Call the Skill tool with "agentic-grill-me", passing focus `product` and this skill's argument (no Skill tool → open `../agentic-grill-me/SKILL.md` and follow it).

Product focus: problem, users, value, success signal, scope and out of scope, why now. Behaviours belong to `agentic-grill-functional`, design to `agentic-grill-tech`.

- **Does it need to exist?** Test every part against the problem and value; push back on any part the need doesn't justify.
- Vague ask → recommend the smallest version that does the core job; the user confirms it.
- Extending an existing feature beats a new one.
